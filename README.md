# Java Microservices — Amigoscode Course

A hands-on Java repository containing exercises and implementations from a microservices learning path based on the Amigoscode course material.

## Topics

- Spring Boot
- REST APIs
- Microservice architecture
- Service-to-service communication
- Spring ecosystem fundamentals
- Application configuration and development practices

## Tech Stack

- Java
- Spring Boot
- Maven
- REST

## Getting Started

Clone the repository and open it in your preferred Java IDE.

```bash
git clone https://github.com/boodyelgml/Java-microservices-amigoscode-course.git
cd Java-microservices-amigoscode-course
```

Run each service according to its Maven configuration.

## Purpose

This repository serves as a practical reference for learning how Java and Spring Boot applications are decomposed and developed as services.
